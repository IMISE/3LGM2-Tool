# Communication links #

Application components can send and/or receive data via component interfaces.
In the service oriented meta model the exchange of data is defined by services.

In order to model, that a communication link exchanges certain data types, first you need to create an appropriate service. Afterwards you have two options:

1. click on the communication link and add the desired service in the **Services** tab
    * this will add the service to both communication links and add the exchanged representation forms accordingly in the **Representation forms** tab
2. click on the communication component and add the desired service in the **Services** tab
    * if both invoking and providing interfaces contain the same service, the respective service will be added to the communication link and the exchanged representation forms are added accordingly in the **Representation forms** tab
