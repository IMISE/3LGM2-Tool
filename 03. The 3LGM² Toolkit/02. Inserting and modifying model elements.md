# Inserting and modifying model elements #

## Inserting model elements ##

You have two multiple options for adding a new model element to your model.:

* You can select a model element from the menu bar from the Insert menu, 
* if the element is a building component that is graphically represented in the model, you can select it from the drawing toolbar, or
* you can right click on the desired element in the model browser. 

Note that you are only provided with model elements that can be used in the selected layer of the model (except for the model browser. 

You can easily select the layer you are working with from the standard toolbar.  

When you insert elements, a dialog appears asking you to give the element a name. After you have assigned a name, press OK to apply the element to your model.  You cannot give a name to an ETNT combination when you create it, because the identifier for this combination is automatically created from the assigned event type and message type or document type.

----------------------

## Changing model elements ##

To modify a model element, double-click the element in the Model Browser or in the document window. A dialog will then open, allowing you to change the properties of this element. In the following, the properties of the elements are explained using the properties dialogs.
