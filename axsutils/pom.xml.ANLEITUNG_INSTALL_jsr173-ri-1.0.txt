Man muss das File manuell installieren, da es in den Maven-Repositories nicht verfügbar ist:

Anleitung siehe: https://stackoverflow.com/questions/14101312/is-it-possible-to-have-a-jar-missing-in-maven-central-repository
Vorraussetzung: auf dem Rechner ist Maven installiert und das mvn-Kommando funktioniert in der Shell (Windows oder OSX oder Linux)

//getestet unter Windows (wie ich das genau unter OSX gemacht habe weiß ich nicht mehr, aber dieser Weg sollte dort auch gehen)

1.) Download: http://svn.apache.org/repos/asf/servicemix/m2-repo/com/bea/xml/jsr173-ri/1.0/
2.) im selben Ordner die Datei jsr173.pom mit folgendem Inhalt anlegen:
<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <groupId>com.bea.xml</groupId>
    <artifactId>jsr173-ri</artifactId>
    <version>1.0</version>
</project>
3.) in der Shell in den Ordner wechseln, in dem die jar und die pom Datei liegen und folgendes Kommando ausführen
mvn install:install-file -Dfile=jsr173-ri-1.0.jar -DpomFile=jsr173.pom
4.) In Eclipse auf dem Projekt, das die jar braucht das Kontextmenü öffen und Maven -> Update Project aufrufen
5.) Eventuell muss man danach für die Projekte wieder einstellen, dass sie mit dem 1.8er JDK gebaut werden sollen, weil Maven das auf 1.5 oder 1.6 zurück setzt
