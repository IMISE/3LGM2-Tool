## Preface ##

Before you start working with the 3LGM²-Tool, you should familiarize yourself with the theoretical principles, i.e., the 3LGM² metamodel. 
These can be found in the 'The 3LGM² Metamodel' section of this Help. The comprehensive functions of the 3LGM²-Tool can quickly make the inexperienced modeler lose track of what is going on. To prevent this from happening and to make it easier to start working with the 3LGM²-Tool, the chapter 'First Steps' has been included in this help.

An overview of the 3LGM²-Tool and the names of the individual graphic elements can be found in the chapter [Overview](https://bitbucket.org/imise/tool-3lgm2/wiki/03.%20The%203LGM%C2%B2-Tool/01.%20Overview).
