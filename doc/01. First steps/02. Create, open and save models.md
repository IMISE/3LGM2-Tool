# Create, open and save models #

## Create a new model ##
To create a new model you have three options: 

1. Open the **File** menu in the menu bar and select **New Model** or
2. Press the key combination **Ctrl + N** or
3. Click the button ![ICON_SMALL_ACTION_NEW_MODEL.gif](https://bitbucket.org/repo/9L6rMz/images/1776909011-ICON_SMALL_ACTION_NEW_MODEL.gif) on the standard toolbar.

In all three cases, a new model with the name *unnamed* will open. A selection dialog box will open first, where you can choose what type of model you want to create.

* Message-based (3LGM² Original)
* Service-oriented with IHE

Once you have saved the model, the name of the file is used as the name for this model.

## Open an existing model ##
To open an existing model you have three options:

1. Open the **File** menu in the menu bar and select **Open** or
2. Press the key combination **Ctrl + O** or
3. Click the button ![ICON_SMALL_ACTION_OPEN_MODEL.gif](https://bitbucket.org/repo/9L6rMz/images/4145674615-ICON_SMALL_ACTION_OPEN_MODEL.gif) on the standard toolbar.

In all three cases, a dialog opens in which you can select the source file of an existing model. 

*Note: Under Windows, you can also open a 3LGM² file by double-clicking on the file, e.g. from Windows Explorer.*

## Save a model ##
You have three options for saving a model:
 
1. Open the **File** menu in the menu bar and select **Save** to save a new model or save an already saved model under the same name. If you have already saved the model you are working with and wish to write it to another file, select **Save As...** from the File menu.
2. Press the key combination **Ctrl + S** or
3. Click the button ![ICON_SMALL_ACTION_SAVE_MODEL.gif](https://bitbucket.org/repo/9L6rMz/images/4024443749-ICON_SMALL_ACTION_SAVE_MODEL.gif) on the standard toolbar.

Have you not yet saved your model or have you selected **Save as ...** a dialog opens in which you can select the folder and the name of the file. If the model has already been saved, the previous file is replaced by the current version of your model.
