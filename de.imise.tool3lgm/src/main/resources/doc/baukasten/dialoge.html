Einfügen und Ändern von Modellelementen

Einfügen von Modellelementen

Sie haben zwei Möglichkeiten ein neues Modellelement in Ihr Modell einzufügen.
Sie können ein Modellelement über die Menüleiste und dort im Menü Einfügen auswählen, oder, wenn es sich bei dem Element um einen Baustein handelt, welcher grafisch im Modell dargestellt wird, diesen aus der Zeichensymbolleiste auswählen.
Beachten Sie, dass Ihnen jeweils nur die Modellelemente zur Verfügung gestellt werden, die in der ausgewählten Ebene des Modells verwendet werden können. Sie können die Ebene mit der Sie arbeiten auf einfache Weise aus der Standardsymbolleiste auswählen.

Beim Einfügen von Elementen erscheint ein Dialog, in dem Sie aufgefordert werden, dem Element einen Namen zu geben. Nachdem Sie einen Namen vergeben haben, drücken Sei OK, um das Element in Ihr Modell zu übernehmen.

Einer ETNT-Kombination können Sie beim Anlegen keine Bezeichnung geben, da für diese der Bezeichner automatisch aus zugewiesenem Ereignistyp und Nachrichtentyp bzw. Dokumenttyp erzeugt wird.

Beim Anlegen eines Anwendungsbausteins werden Sie vor der Vergabe des Namens für diesen Baustein zusätzlich aufgefordert den Typ des Bausteins (konventionell, rechnerbasiert oder gemischt) anzugeben.

Ändern von Modellelementen

Zum Ändern eines Modellelements doppelklicken Sie auf das Element im Modellbrowser oder im Dokumentfenster. Es öffnet sich dann ein Dialog, mit dem Sie die Eigenschaften dieses Elements verändern können. Im Folgenden werden die Eigenschaften der Elemente anhand der Eigenschaftsdialoge erklärt.
