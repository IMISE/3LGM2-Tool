Vergröbern und Verfeinern eines Modells

Über die ist_Teil_von Beziehungen ist es möglich Modelle zu vergröbern und zu verfeinern. Verfeinern und Vergröbern ist keine Funktion, die im Rahmen der Modellierung verwendet wird ("Ich möchte jetzt eine Aufgabe verfeinern") - dies ist lediglich durch die ist_Teil_von Beziehungen möglich -, sondern eine Funktion, die auf einem 'fertigen' Modell angewendet wird. Hierdurch können Modelle besser visualisiert werden und auf einer beliebig groben Ebene analysiert werden. Die Funktionen Vergröbern und Verfeinern beziehen sich auf Modellelemente.

Für das Vergröbern und Verfeinern gibt es folgende Regeln:
  • Beziehungen von Elementen sind auf einer möglichst tiefen Hierarchiestufe zu modellieren.
  • Beim Vergröbern eines Modells werden Beziehungen der untergeordneten an das übergeordnete Element dynamisch übergeben.
  • Beim Verfeinern eines Modells werden Beziehungen, die dem übergeordneten Element aufgrund einer Vergröberung auf der entsprechenden Hierarchieebene dynamisch zugerordnet wurden wiederum an die untergeordneten Elemente (zurück-) gegeben; d.h. sie werden einfach dem übergeordneten Element wieder weggenommen.
  • Analyse- und Exportfunktionen arbeiten immer auf dem jeweiligen aktuellen (vergröberten oder verfeinerten) Modell.
  • Für Anwendungsbausteinkonfigurationen gilt beim Vergröbern folgendes: Die Anwendungsbausteinkonfiguration der übergeordneten Aufgaben entstehen durch Bildung des Kreuzproduktes der Mengen der Anwendungsbausteinkonfigurationen der untergeordneten Aufgaben (siehe Abb. 1). Anwendungsbausteinkonfigurationen, die der übergeordneten Aufgabe bereits vorher zugeordnet waren, bleiben erhalten. Dies kann bei einer großen Anzahl von ist_Teil_von Beziehungen und einer großen Anzahl von Anwendungsbausteinkonfigurationen für die untergeordneten Aufgaben dazu führen, dass dem übergeordneten Anwendungsbaustein eine sehr große Anzahl an AB-Konfigurationen zugeordnet ist. Entsprechendes gilt für Datenverarbeitungsbausteinkonfigurationen.

Abb. 1: Anwendungsbausteinkonfigurationen beim Vergröbern eines 3LGM² Modells.
