## Starting 3LGM2 Tool (ToDo: Move to 1. steps)##
* start 3LGM2 Tool from menu of your Operating System (Windows, Linux¹, Mac OS¹)
* start 3LGM2 Tool from command line
* start 3LGM2 Tool by clicking a model file (only supported in Windows)
* start multiple instances of 3LGM2 Tool
    * use the command line parameter '-n'

## Example Models
It is advised to read the further chapters if you want to go into further detail of your model.
The tool also offers an example model, this can give you insight of how the tool can be used. In order to access this go to *Help* in the menu bar and select the example model.
