# Userfields and subtypes #

## Definition ##
* via the menu item 'Extras' -> 'Create User-Defined Property Fields'
* In the following dialog you can now
    * select the element class for which userfields should be added
    * select the type of userfield to be added
    * add a userfield via the 'New' button
    * change the order of the userfields of an element type
    * switch on/off if a userfield should be displayed in the model browser
    * switch on/off if the description of a userfield should be displayed in the dialog
    * export the complete definition of userfields (to a special XML file) or import it into the current model
* All userfields are in a list. The position of a userfield in this list determines how it is interpreted.
* The first userfield is either a TAB or a SUBTYPE. If it is a TAB, then this userfield defines a tab that is displayed for all elements of the current element type in the properties dialog.
* All userfields following this TAB userfield in the list are displayed on this tab in the properties dialog until either another TAB userfield is in the list or a SUBTYPE userfield.
* Another TAB user field defines another tab in the properties dialog, which again contains all user fields following in the list, until a SUBTYPE or TAB follows.
* A SUBTYPE defines a subelement type. All subtypes can be created directly as such, or a subtype can be given to or removed from an element (via its properties dialog).
* Elements with a subtype have in their properties dialog all tabs defined for the upper element type and all tabs defined for this subtype.
